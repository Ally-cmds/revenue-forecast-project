# Power BI Review Dashboard — Build Guide

Present the forecast results in Power BI using the fact tables the pipeline
already publishes as CSV. Total build time after install: about 15 minutes.

## 0. Install

- **Power BI Desktop** — free, from the Microsoft Store (Windows).

## 1. Load the data

`Get Data` → `Text/CSV`, then load each file (all paths relative to the repo root):

| File | Table name to use | Rows |
|---|---|---|
| `outputs/tableau/fact_forecast_accuracy.csv` | `fact_forecast_accuracy` | 524 (one per company-quarter) |
| `outputs/tableau/fact_company_league.csv` | `fact_company_league` | 10 |
| `outputs/tableau/fact_error_by_year.csv` | `fact_error_by_year` | 15 |

After each load, open **Transform data** and set types:

- `quarter_end` → **Date**
- `year` → Whole Number; `quarter_num`, `n_quarters`, `ease_rank` → Whole Number
- `within_5pct` → Whole Number (0/1)
- `actual`, `fc_*` → Decimal Number; `var_*`, `mape_*`, `avg_mortgage_rate` → Decimal Number

## 2. Relationships (Model view)

1. `fact_forecast_accuracy[ticker]` → `fact_company_league[ticker]`, **Many to one**, cross filter: Single
2. `fact_forecast_accuracy[year]` → `fact_error_by_year[year]`, **Many to one**, Single

Turn **off** auto-detect surprises: Power BI may also try to link `sector`; delete any
unwanted auto-created relationships.

## 3. DAX measures (Modeling → New measure)

```dax
Quarters reviewed =
COUNTROWS ( fact_forecast_accuracy )

Overall MAPE (Chosen) % =
DIVIDE (
    SUMX ( fact_company_league, fact_company_league[n_quarters] * fact_company_league[mape_chosen_pct] ),
    SUMX ( fact_company_league, fact_company_league[n_quarters] )
)

Coverage within 5% =
AVERAGE ( fact_forecast_accuracy[within_5pct] )

Avg mortgage rate =
AVERAGE ( fact_error_by_year[avg_mortgage_rate] )

Ridge penalty (pp) =
AVERAGEX (
    fact_forecast_accuracy,
    ABS ( fact_forecast_accuracy[var_ridge_pct] ) - ABS ( fact_forecast_accuracy[var_chosen_pct] )
)
```

Format: `Overall MAPE` and `Ridge penalty` as `0.00`, `CoverageWithin5` as percentage `0.0%`.

## 4. Page layout (MIS review style)

Suggested one-page layout, mirroring the Excel workbook's traffic-light language:

1. **Card row (top):** `Overall MAPE (Chosen)`, `Coverage within 5%`, `Quarters reviewed`, `Avg mortgage rate`
2. **Slicers (left):** `year` (list), `sector`, `zone_chosen` (buttons: on plan / review / escalate)
3. **Combo chart (center):** columns = `mape_chosen_pct`, `mape_ridge_pct`, `mape_naive_pct`; line = `avg_mortgage_rate`; x = `year` (use `fact_error_by_year`)
4. **League table (right):** ticker, ease_rank, mape_chosen_pct, mape_ridge_pct, chosen_minus_ridge — with **data bars** on `mape_chosen_pct`
5. **Matrix (bottom):** rows = `ticker`, columns = `year`, values = `var_chosen_pct` (title: Variance vs chosen forecast)

## 5. Conditional formatting (the RED/AMBER/OK rules)

Same thresholds as the pipeline and Excel workbook:

- Background rules on the matrix `var_chosen_pct`: **±5% → green**, **±10% → yellow**, beyond → **red**
- Font rule on `chosen_minus_ridge`: **< 0 → green** (chosen model beats ridge), **> 0 → red**
- Zone legend: `on plan` = green, `review` = amber, `escalate` = red

Title the page **"Revenue Forecast Review — MIS"**.

## 6. Refresh / regenerate data

The CSVs are regenerated by the pipeline whenever the backtest reruns:

```
python -m scripts.make_tableau_export
```

In Power BI: `Refresh` picks up updates only if file paths are unchanged, which they are.
Full provenance of every number: see `README.md` (pipeline + locked-test rules) and
`forecast.sql` (the MySQL-style mirror of these tables).
